# 常见问题（FAQ / 排错）

> 用户向。开发问题见 [`DEVELOPMENT.md`](DEVELOPMENT.md)。

## 鉴权 / 登录

**Q：用了 2 小时就报 `Feishu API error (code=99991677): token expired`？**
飞书 `user_access_token` 只活 ~2 小时，靠 `refresh_token` 续期。若没续期，多半是**授权时缺 `offline_access` scope**。
- 代码已**始终请求 `offline_access`**；但需**重新授权一次**（旧 token 没带 refresh_token）。
- 后台「权限管理」确认 `offline_access` 已开通，重新授权后自动续期。

**Q：报「请先用飞书账号授权」/ 401 / 登录失效？**
顶部出现「飞书登录已失效」横幅，点它回设置**重新授权**。助手只以**你本人身份**操作。

**Q：`403 / 无编辑权限`？**
该文档/表格不是你创建的或没共享给你。用有权限的账号操作，或在「分享」里把自己加为可编辑。助手**不会越权**。

**Q：加密版打不开（解锁密码）？**
密文版需在 **设置 → 飞书设置 → 输入解锁密码** 解锁一次。密码在打包时由 `scripts/encrypt-secret.mjs` 设定。

## 生成 / 导出

**Q：PPT / 看板点「导出 PDF」没反应？**
重新加载扩展后，用浮窗标题栏的 **🖨** 即可（PPT 一页一张）。

**Q：提示十几秒，实际几十秒？**
PPT/报告是多步 LLM 生成，**几十秒起**属正常。耐心等待或点「取消」。

**Q：切标签回来，生成内容丢了？**
不会。看板/幻灯片结果按页面缓存，回来自动恢复；保存过的在列表里。

**Q：怎么调配色？**
浮窗标题栏取色器：预设色 + 自定义，实时给 PPT/看板/图表换色。

## 数据 / 升级

**Q：版本更新会丢已保存的看板/PPT 吗？**
不会。存在 `chrome.storage.local`（PPT=`slides_decks_v1`，看板=`dataviz_v1`），更新扩展不清空。只有**卸载重装**或**扩展 ID 变了**才会丢。

**Q：知识库（Wiki）里的表格识别不出？**
已支持——会自动把 Wiki 解析成背后的真实表格/文档。识别不出时直接打开本体。

**Q：会把数据发给大模型吗？**
只有执行你明确发起的任务时，才把**必要且有上限**的数据发给**你自己配置**的大模型；沙箱里运行的生成代码 `connect-src 'none'`，**拿了数据也发不出去**。

## 安装

**Q：`.crx` 拖进去装不上？**
普通 Chrome 默认禁装商店外 `.crx`。个人用**解压 zip → 开发者模式 → 加载已解压**最稳。

**Q：大模型 Key 在哪填？**
**设置 → 模型配置**里自填（OpenAI 兼容，默认 DeepSeek），仅存本机、加密保存。
